# Movie Recommendation System 

A content-based movie recommendation system built using Machine Learning and Streamlit.

## Features
- Recommend similar movies based on user selection
- Fetch movie posters using TMDB API
- Interactive Streamlit web application

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- TMDB API

## Project Files
- MovieRecommendation.ipynb - Model development
- app.py - Web application
- movie_list.pkl - Movie data
- similarity.pkl - Similarity matrix (not included due to GitHub file size limit)

## Dataset
TMDB 5000 Movies Dataset
